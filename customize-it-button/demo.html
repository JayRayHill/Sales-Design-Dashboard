Feasibility & build notes

  • Fully feasible, pure CSS. A rotating conic-gradient of your brand colors is blurred into a liquid wash behind a translucent pane with backdrop-filter. No images, no JavaScript, no apps — one Liquid snippet.
  • Hover is theme-exact. Canopy's default CTAs hover with one motion only: a 104° diagonal color wipe (an oversized gradient sliding with ease-out) — no lift, no glow, no sweep. This button does precisely that and nothing else: the frost floods away at 104° with the same easing, eased to 0.6s (vs the theme's 0.4s) so the glass reveal breathes a touch more. Only the Raised and Domed depth options add a lift on top, since dimension is their entire purpose.
  • On brand, per the new design system. The current runs Roasted dark → Roasted → Brew → Iced light → Iced dark, weighted warm with one cool pass. Label is Ink, focus ring is Roasted, radius and shadows follow the token scale. One flag: the guide scopes Iced teal to cold-product sections — here it appears only as a moving accent inside the glass, which reads intentional, but it's a one-line change to drop it if you want to stay strictly warm.
  • Why the color lives inside the glass: on your white product pages a plain frosted blur would be invisible (blurred white is white). Giving the glass its own internal color current is what creates the liquid-glass depth — and it's what lets the color move.
  • Browser support: works in all current Chrome, Safari, Edge and Firefox (with the -webkit- prefix included for Safari). A clean solid-frost fallback is included for anything older.
  • Respectful motion: the rotation is a 10-second drift, not a spin, and it fully honors prefers-reduced-motion. Speed is one variable: --hcf-aura-speed.
  • Drop-in install: the production version wraps the designer flow — it renders only when a product has both customizer.type and customizer.size set, and links cross-domain to the UNIQ-hosted designer (uniqsupply.com/pages/custom-designer) with brand=hcf, which the app already re-skins to Hot Cup Factory. Adds via one {% render %} line; opens in a new tab.
  • Small upgrade included: the old markup nested a <button> inside an <a> (invalid HTML). The new version is a single styled link with a proper aria-label and focus state.
